## 📌 Project Overview

**CodeAlpha Portfolio** is a personal portfolio website created as part of the **CodeAlpha one-month Front-End internship**. It showcases the developer's skills, projects, and experience through a clean, responsive interface built with pure HTML, CSS, and JavaScript.

---

## ✨ Key Features

- 🎨 **Modern Responsive Design** – Adapts to desktop, tablet, and mobile screens
- 🧩 **Reusable Components** – Organized CSS and script folders for maintainability
- 🖼️ **Image Assets** – Dedicated `img/` folder for portfolio visuals
- ⚡ **No Dependencies** – Pure HTML/CSS/JS, no frameworks or build tools

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Page structure |
| **CSS3** | Styling and responsive layout |
| **JavaScript** | Interactivity and dynamic content |

## 📁 Project Structure

```
CodeAlpha_Protfolio/
├── index.html      # Main portfolio page
├── css/            # Stylesheets
├── script/         # JavaScript files
└── img/            # Images and assets
```

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/AmjadIbrahim1/CodeAlpha_Protfolio.git
   ```
2. Open `index.html` in any modern web browser.
3. No installation or build step required.
